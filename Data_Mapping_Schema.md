# Data Mapping and Schema Dictionary

## Overview
This document outlines the data mapping required to maintain referential integrity across the CRM, the Data Center Provisioning Engine, and the Financial/Billing System.

## Unified Client Identity Mapping

| CRM Field (Source) | Provisioning Engine Field | Billing System Field | Data Type | Constraint/Rule |
| :--- | :--- | :--- | :--- | :--- |
| `client_uuid` | `owner_id` | `customer_ref_id` | VARCHAR(36) | Primary Key, Not Null |
| `company_name` | `tenant_name` | `billing_entity` | VARCHAR(255) | Must match official registry |
| `service_tier` | `resource_allocation_limit` | `subscription_plan` | ENUM | Limits: Standard, Pro, Enterprise |
| `admin_email` | `tech_contact_email` | `invoice_email` | VARCHAR(120) | Must be valid email format |
| `activation_date` | `deployment_timestamp` | `billing_start_date` | DATETIME | ISO 8601 Format (UTC) |
| `system_status` | `node_health_status` | `account_standing` | BOOLEAN | 1 = Active, 0 = Suspended |
